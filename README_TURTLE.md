# Space Shooter (Turtle Version) - by kanak Dovloper

A modern space shooter built with Python's built-in Turtle module.

## Features
- Arrow key movement
- Spacebar shooting
- Enemy wave system
- Score tracking
- Lives system
- Clean cyan/red/yellow theme

## Run Game
```bash
python turtle_space_shooter.py
```

## Controls
- Left/Right/Up/Down Arrow Keys - Move
- Spacebar - Fire
