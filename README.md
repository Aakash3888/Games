# Space Shooter - by kanak Dovloper

A modern, stylish space shooter game built with Python and Pygame.

## Features
- Smooth player movement with arrow keys
- Shoot enemies with spacebar
- Animated explosions
- Shield system and lives
- Scrolling star background
- Progressive difficulty
- Modern UI design

## Installation

1. Install Python 3.8+ 
2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the game:
```bash
python main.py
```

## Controls
- Arrow Keys - Move ship
- Spacebar - Shoot
- Enter - Start/Restart
- ESC - Quit
